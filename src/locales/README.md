# Local message catalogs

Narration variants are local templates. Selecting a language or narration mode never calls a model.

`minecraft-pt-BR.json` contains the Brazilian Portuguese item, block, entity, biome, enchantment and effect labels from the official Minecraft Java 26.1.2 language asset. Its `source` field records the original asset URL and SHA1. The original installed asset and its version asset index were verified against their SHA1 hashes before extracting these labels. The game and its assets do not need to be installed at runtime.

The names belong to Minecraft/Mojang; this file does not change the game's content. Unknown identifiers retain a readable name so newer or custom server content remains usable.
